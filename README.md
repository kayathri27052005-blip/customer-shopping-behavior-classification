# Customer Shopping Behavior Classification using Machine Learning

## 📌 Project Overview
This project predicts customer shopping behavior using machine learning classification algorithms. The goal is to analyze customer information and predict purchasing behavior to help businesses improve marketing strategies and customer engagement.

## 🎯 Problem Statement
Businesses need to understand customer shopping behavior to provide personalized recommendations, improve customer satisfaction, and increase sales.

- Scikit-learn

- Random Forest
- XGBoost (if used)
